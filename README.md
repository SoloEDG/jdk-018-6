# GLYPH ASCII Studio

安装：`npm ci`

本地启动：`npm run dev`

Docker 启动：`docker compose up --build`，访问 http://localhost:18018。

## 区域规则

- 左侧「02 / CROP & REGIONS」切换到「区域规则」，在原图上拖动即可圈出区域；可重叠、可拖角缩放。
- 每个区域独立设置字符集、密度倾向 (±100%)、对比度、伽马与反转；未覆盖部分继续使用「03 / BASE MAPPING」的基础映射。
- 列表顺序即优先级（P1 最高），重叠处的每个格子按采样中心判定唯一归属，跨边界不会随机漂移。
- 所有区域共用同一行列数的热图网格：字符密度（列数）始终由基础映射控制，区域只改变解释方式，因此 TXT / 复制结果仍是行列对齐的单一字符网格。
- 区域用原图坐标保存，改变裁剪只是移动取景框，区域不会跟着缩放或改写。
- 「区域规则」预览页的归属着色与图例、单元格点击解释、优先级上/下移提示、删除前后接管说明，以及「规则」导出的逐行归属清单，共同说明最终字符由哪条规则决定。
